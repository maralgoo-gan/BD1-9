# Программын UI дээр гараар хийх туршилтын жишээнүүд
# Эдгээр нь CLI команд биш, дэлгэцийн тохиргоо юм.

ТУРШИЛТ A — Зэрэгцээ ажиллагаа
Ажиллагчдын тоо=3, Дарааллын багтаамж=30, Нэмэх ажлын тоо=8, Хугацаа=2000 мс, Төрөл=Хүлээлт.
«Сан үүсгэх» → «Ажил нэмэх». Дууссаны дараа: ДУУССАН=8, ХҮЛЭЭЖ БУЙ=0, АЖИЛЛАЖ БУЙ=0.

ТУРШИЛТ Б — Нэг ажиллагч
«Шинэчлэх» → Ажиллагчдын тоо=1, Багтаамж=30, Ажил=6, Хугацаа=1000 мс, Төрөл=Хүлээлт.
«Сан үүсгэх» → «Ажил нэмэх». Хугацааны шугамд ажлууд цуварч гүйцэтгэгдэх ёстой.

ТУРШИЛТ В — Дараалал дүүрэх
«Шинэчлэх» → Ажиллагч=1, Багтаамж=1, Ажил=20, Хугацаа=5000 мс, Төрөл=Хүлээлт.
«Сан үүсгэх» → «Ажил нэмэх». Зарим ажил нэмэгдэж, бусад нь татгалзагдана; программ гацах ёсгүй.

ТУРШИЛТ Г — Interrupt / Зогсоох
«Шинэчлэх» → Ажиллагч=3, Багтаамж=30, Ажил=15, Хугацаа=5000 мс, Төрөл=Хүлээлт.
«Сан үүсгэх» → «Ажил нэмэх» → дуусахаас өмнө «Зогсоох».
Хүлээж буй ажлууд цуцлагдаж, ажиллаж буй урсгалуудад interrupt илгээгдэнэ.

ТУРШИЛТ Д — Алдаанаас сэргэх
«Шинэчлэх» → Ажиллагч=2, Багтаамж=30, Ажил=3, Хугацаа=1000 мс, Төрөл=Алдаа шалгах.
«Сан үүсгэх» → «Ажил нэмэх». АЛДААТАЙ=3, ажиллагч урсгалууд зогсоогүй байна.
Дараа нь ажлын төрлийг Хүлээлт болгож 3 ажил нэмэхэд ДУУССАН=3 болох ёстой.
