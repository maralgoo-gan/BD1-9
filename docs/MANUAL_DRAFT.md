# Хэрэглэгчийн болон operational гарын авлагын эх загвар

> Энэ нь багшид явуулах эцсийн PDF биш. Багийн бодит GitHub URL, Mac дээрх шалгалт, screenshot-ийг нэмээд `Manual.pdf` болгож хадгална.

## 1. Зорилго

Энэ программ Java-ийн бодит урсгалуудыг ашиглан Thread Pool-ийн ажиллагааг харуулна. Хэрэглэгч ажиллагчдын тоо, хүлээлгийн дарааллын багтаамж, ажлын тоо, хугацаа, төрлийг өөрчилж, үйл явдлын түүх болон хугацааны шугамаар ажиглана.

## 2. Шаардлагатай орчин

macOS / Windows / Linux desktop орчин; JDK 17 эсвэл 21; Terminal. VS Code сонголтоор ашиглана. Нэмэлт Java framework хэрэггүй.

## 3. Mac дээр ажиллуулах

1. GitHub repository-оос ZIP татаж задлах эсвэл `git clone` хийх.
2. VS Code → **File → Open Folder** → төслийн хавтас сонгох.
3. **Terminal → New Terminal** нээх.
4. `java -version` болон `javac -version` ажиллуулж Java суусныг шалгах.
5. Төслийн үндсэн хавтаснаас `bash run.sh` ажиллуулах.
6. «УРСГАЛЫН САН / АЖИЛЛАГЧДЫН ТӨЛӨВ» цонх нээгдэнэ.

## 4. Үндсэн удирдлага

| Дэлгэц дээрх текст | Хийх үйлдэл |
|---|---|
| Ажиллагчдын тоо | 1–32 ажиллагч урсгал сонгоно |
| Дарааллын багтаамж | 1–1000 хүлээлгийн ажлын хязгаар сонгоно |
| Нэмэх ажлын тоо | 1–100 ажил нэг удаад нэмнэ |
| Хугацаа (мс) | Ажлын хугацааг миллисекундээр сонгоно |
| Ажлын төрөл | Хүлээлт, CPU тооцоолол, Алдаа шалгах |
| Сан үүсгэх | Шинэ pool үүсгэнэ |
| Ажил нэмэх | Сонгосон ажлуудыг queue-д нэмнэ |
| Зогсоох | Queue-д хүлээсэн ажлыг цуцалж, thread-д interrupt өгнө |
| Шинэчлэх | Өмнөх санг бүрэн зогсоож шинэ тохиргоо оруулна |

**Төлөвийн утга:** СУЛ, АЖИЛЛАЖ БУЙ, ДУУССАН, АЛДААТАЙ, ЦУЦЛАГДСАН, ЗОГССОН. Ногоон зурвас — ажиллаж буй; саарал зурвас — сул; тод цэнхэр босоо тэмдэг — ажил амжилттай дууссан агшин; улаан нарийн босоо тэмдэг — worker зогссон агшин (алдаа/цуцлалтын тэмдэг ч мөн улаан байж болно). **Зогссоноос хойш улаан зурвас сунгахгүй, бүх worker зогссон үед хугацааны шугам царцана.**

**Анхаар:** `ДУУССАН` нь task-ийн төлөв. Ажиллагч дууссан event-ийг бүртгээд буцаад `СУЛ` болдог.

## 5. Туршилт 1 — 3 ажиллагч, 8 ажил

Ажиллагчдын тоо=`3`; багтаамж=`30`; нэмэх ажлын тоо=`8`; хугацаа=`2000` мс; төрөл=`Хүлээлт (I/O загвар)`. «Сан үүсгэх» → «Ажил нэмэх» дарна. 3 ажиллагч зэрэг ажиллаж, үлдсэн ажил queue-д хүлээнэ. Дуусахад Нийт=8, Хүлээж буй=0, Ажиллаж буй=0, Дууссан=8 хүлээгдэнэ.

## 6. Туршилт 2 — 1 ажиллагч

«Шинэчлэх» дараад ажиллагч=`1`, ажил=`6`, хугацаа=`1000` мс болгож ажиллуул. Ажлууд ээлжлэн ажиллаж буйг хугацааны шугамаар харьцуул.

## 7. Туршилт 3 — Алдаатай ажил

Төрлийг «Алдаа шалгах» болгож 2 ажил нэм. `АЛДААТАЙ` төлөв харагдаж, ажиллагч дараагийн ажлыг гүйцэтгэхэд бэлэн үлдэх ёстой.

## 8. Operational: compile, run, test

```bash
java -version
javac -version
bash run.sh
bash test.sh
```

`bash test.sh` нь үндсэн 7 бүлгийн тестийн араас Timeline-ийн зогссон үеийн шинэ regression тестийг ажиллуулна.

Гараар compile/run хийх шаардлагатай бол:

```bash
mkdir -p out
javac -encoding UTF-8 -d out src/*.java
java -Dfile.encoding=UTF-8 -cp out Main
```

GUI тест (desktop шаардана):

```bash
javac -encoding UTF-8 -d out src/*.java tests/*.java
java -Dfile.encoding=UTF-8 -cp out GuiSmokeTest
```

## 9. Алдаа ба шийдэл

- `javac: command not found` — Java JDK суулгаж, Terminal-аа дахин нээгээд шалгах.
- Java-ийн хувилбар олдохгүй — JDK 17/21 эсэхийг шалгах.
- `Could not find or load main class Main` — төслийн үндсэн хавтсаас `bash run.sh` ажиллуулах.
- «Ажлын дараалал дүүрсэн» — багтаамж өсгөх эсвэл ажил дууссаны дараа дахин нэмэх.
- «Ажил нэмэх» идэвхгүй — эхлээд «Сан үүсгэх» дарна.
- Worker-ийн тоог өөрчлөх боломжгүй — «Шинэчлэх» дарж шинэ сан үүсгэнэ.
- Дэлгэц жижиг — цонхыг томруулж, дэлгэцийн нягтралыг шалгах.

## 10. Known issues / хязгаарлалт

Номын Java хувилбарын дагуу `shutdown()` нь interrupt өгнө. Queue-д хүлээсэн ажлууд цуцлагдана. CPU scheduling-ийг үйлдлийн системийн түвшинд хянахгүй. Жишээ screenshot-ууд Linux/Xvfb дээр авсан; Mac-тай холбоотой баталгаажуулалтыг багийн гишүүд нэмж оруулна.
