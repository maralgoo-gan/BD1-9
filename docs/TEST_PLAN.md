# Тестийн төлөвлөгөө — №9 Урсгалын сан

`bash test.sh` ажиллуулж, бодит Mac/Java хувилбараа тайланд тэмдэглэнэ. Тест бүрийн бодит гаралт, шаардлагатай screenshot-ийг хадгална.

| Код | Туршилт | Хүлээгдсэн үр дүн |
|---|---|---|
| T1 | 3 ажиллагч, ажил 0 | 3 ажиллагч үүсэж, бүгд `IDLE` |
| T2 | 3 ажиллагч, зэрэг эхлэх 3 ажил | Хүлээлт сулрахаас өмнө гурвуулаа `RUNNING` |
| T3 | 1 ажиллагч, queue багтаамж 1, нийт 3 ажил | 1 нь ажиллаж, 1 нь хүлээнэ; 3 дахь нь татгалзагдана |
| T4 | 5 ажиллагч, 500 тоолуур өсгөх ажил | 500 ажил яг нэг удаа гүйцэтгэгдэж, ID бүр өөр байх |
| T5 | Алдаатай `Runnable` дараа зөв `Runnable` | `FAILED=1`; worker зогсолгүй дараагийн ажлыг гүйцэтгэх |
| T6 | 1 ажиллаж буй ба 1 хүлээж буй task-тэй үед shutdown | Ажиллаж буйд interrupt; хүлээж буйг цуцалж, pool дуусах |
| T7 | Ажиллагч=0, хугацаа=-1, shutdown-ы дараа add() | Буруу хүсэлтүүдийг хүлээж авахгүй |
| T8 | 2 ажиллагч, 2 ажил дууссаны дараа shutdown, 0.5 сек хүлээх | Цагийн хуваарь царцаж, цэнхэр дууссан тэмдэг тод, улаан STOPPED зурвас сунахгүй |
| UI1 | 3 ажиллагч, 8 хүлээлтийн ажил | `ДУУССАН=8`; UI болон Timeline-ийг шалгах |
| UI2 | Reset хийх | Хуучин pool эцэслэж, тохиргоо дахин идэвхжих |
| UI3 | 1 ажиллагч болгож давтах | Ажлууд дарааллан гүйцэтгэгдэх |
| UI4 | «Алдаа шалгах» төрөл | `АЛДААТАЙ` тоолуур өсч, ажиллагч үргэлжлүүлэх боломжтой |
| UI5 | Queue багтаамж 1, олон ажил | Дарааллын хязгаарын Монгол мэдэгдэл гарч, төлөв зөв үлдэх |

**Анхаар:** Thread scheduling deterministic биш. Worker бүр яг ямар task авах, дуусах дарааллыг хатуу тулгахын оронд task алдагдсан/давхардаагүй, тоолуурын invariant үнэн эсэхийг шалгана.

**Хамрах хүрээ:** Хавсаргасан автомат шалгалтуудыг Linux/OpenJDK 21 орчинд хийсэн. Mac дээр хийх ажил тусдаа баталгаажуулалт байх ёстой.
