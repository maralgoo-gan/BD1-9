# Урсгалын сан — Ажиллагчдын төлөв | Бие даалт 1, №9

**Хичээл:** F.CSM302 Үйлдлийн систем  
**Төсөл:** Designing a Thread Pool (Worker Activity)  
**Сурах бичиг:** A. Silberschatz, P. B. Galvin, G. Gagne, *Operating System Concepts*, 10 дахь хэвлэл, 2018, 7-р бүлгийн Programming Projects, Project 1 (PDF-ийн 405–408-р хуудас, номын P-35–P-38).  
**Технологи:** Java 17/21, Swing, `Thread`, `Runnable`, `synchronized`, `wait()`, `notifyAll()`, `interrupt()`.

## 1. Төслийн зорилго

Урьдчилан үүсгэсэн олон **ажиллагч урсгал** (worker thread) нэг **ажлын дараалал** (task queue)-аас ажил авч зэрэгцэн гүйцэтгэх механизмыг бодитоор хэрэгжүүлсэн. Үндсэн код нь номын Java API-г хэрэгжүүлдэг бөгөөд бэлэн `ExecutorService`-ээр thread pool байгуулаагүй.

Программын UI дээр **ажиллагчдын тоо**, **хүлээлгийн дарааллын багтаамж**, **нэг удаад нэмэх ажлын тоо**, **ажлын хугацаа** болон **ажлын төрлийг** өөрчилж болно. Ажиллагчдын төлөв, хугацааны шугам, ажлын түүх, үйл явдлын бүртгэл нь бодит Java урсгалуудын үүсгэсэн өгөгдөлтэй холбогдоно.

## 3. Товчлуур болон тохиргоо

| Программ дээрх нэр | Утга |
|---|---|
| **Ажиллагчдын тоо** | Урьдчилан үүсэх Java worker урсгалын тоо (1–32) |
| **Дарааллын багтаамж** | Зөвхөн **хүлээж буй** ажлын дээд тоо (1–1000); ажиллаж буй ажлыг тооцохгүй |
| **Нэмэх ажлын тоо** | «Ажил нэмэх» дарахад хэдэн task дараалалд оруулах (1–100) |
| **Хугацаа (мс)** | Нэг ажлын үргэлжлэх хугацаа, миллисекунд (100–15000) |
| **Ажлын төрөл — Хүлээлт (I/O загвар)** | Сонгосон хугацаагаар `Thread.sleep()` хийнэ |
| **CPU тооцоолол** | Жинхэнэ CPU тооцоолол хийх туршилт |
| **Алдаа шалгах** | Зориуд exception үүсгэж error handling-ийг шалгах |
| **Сан үүсгэх** | Тохиргооны дагуу бодит ажиллагч урсгалуудыг үүсгэнэ |
| **Ажил нэмэх** | Ажлуудыг queue-д нэмнэ; дүүрсэн бол илүүдлийг татгалзана |
| **Зогсоох** | Хүлээж буй ажлуудыг цуцалж, ажиллагч урсгалд `interrupt()` илгээнэ |
| **Шинэчлэх** | Өмнөх санг зогсоон, тохиргоог дахин сонгох боломж олгоно |

**Төлөвийн тайлбар:**

- **СУЛ** — ажиллагч шинэ ажил хүлээж байна (`IDLE`).
- **АЖИЛЛАЖ БУЙ** — ажиллагч нэг ажлыг гүйцэтгэж байна (`RUNNING`).
- **ДУУССАН** — task амжилттай дууссан (`COMPLETED`), ажиллагч дахин `СУЛ` болно.
- **АЛДААТАЙ** — task exception-оор дууссан (`FAILED`).
- **ЦУЦЛАГДСАН** — ажил эхлэхээс өмнө эсвэл гүйцэтгэж байх үед зогсоосон (`CANCELLED`).
- **ЗОГССОН** — ажиллагч урсгал эцэслэсэн (`STOPPED`).

**Хугацааны шугам:** ногоон зурвас = ажиллаж буй, саарал = сул, цэнхэр БОСОО тэмдэг = амжилттай дууссан task-ийн агшин, улаан БОСОО тэмдэг = worker зогссон агшин (мөн алдаа/цуцлалтын агшны улаан тэмдэг байж болно). Зогссоноос хойш улаан өнгө үргэлжилж сунгахгүй; бүх worker зогсмогц цагийн хуваарь царцана. Хугацаа нь сан үүсгэснээс хойших секунд.

## 4. Үндсэн жишээ туршилт

**Жишээ 1: 3 ажиллагч, 8 ажил**

1. Ажиллагчдын тоо = `3`; дарааллын багтаамж = `30`.
2. Нэмэх ажлын тоо = `8`; хугацаа = `2000` мс; төрөл = `Хүлээлт (I/O загвар)`.
3. **«Сан үүсгэх» → «Ажил нэмэх»** дарна.
4. Эхний 3 ажил worker-үүдэд оноогдож, үлдсэн ажил хүлээнэ. Ажил дуусах тусам queue багасна.
5. Бүгд амжилттай дуусахад: **Нийт=8, Хүлээж буй=0, Ажиллаж буй=0, Дууссан=8**.

**Жишээ 2: ажиллагчдын тоог солих**

«Шинэчлэх» дарж ажиллагчдын тоог `1` болгоно. 6 ажил, хугацаа `1000` мс өгөөд дахин ажиллуул. Нэг ажиллагчтай үед ажлууд ээлжлэн явахыг хугацааны шугамаар ажиглана.

**Жишээ 3: алдааны шалгалт**

Ажлын төрлийг «Алдаа шалгах» сонгож ажил нэм. Ажлууд `АЛДААТАЙ` болох ба ажиллагч урсгал гацалгүй дараагийн ажил авах боломжтой байх ёстой.

## 8. Хязгаарлалт ба ил тод байдал

- Энэ нь үйлдлийн системийн **kernel scheduler биш**, хэрэглээний түвшний бодит Java thread pool.
- «Хүлээлт» горим I/O-г `sleep()`-ээр **загварчилдаг**. «CPU тооцоолол» бодит арифметик үйлдэл хийдэг.
- Ажиллагч тоо өсөхөд бодит хурд үргэлж шугаман өсөх албагүй.
- Queue-ийн FIFO нь ажил **авах дарааллыг** удирдана; гүйцэтгэл **дуусах дараалал** өөр байж болно.
- Shutdown нь queue-г дуусгахыг хүлээх биш, **interrupt + cancel** механизмаар ажиллана. Interruption-ийг үл тоодог өөр task зогсохдоо удааширч болно.
- Жишээ кодыг Linux/OpenJDK 21 дээр compile, тест хийсэн. **Mac дээр хийсэн тестийг багийн гишүүд өөрсдөө шалгаж, баримтжуулах ёстой**.
- Эх код, UI болон бичиг баримтыг боловсруулахад ашигласан гадаад эх сурвалж, бэлэн код, AI туслалцааг багшийн удирдамжийн дагуу эцсийн тайланд тодорхой бичнэ.

**Анхаарах зүйл:** `docs/REPORT_OUTLINE.md`, `docs/MANUAL_DRAFT.md` нь **эцсийн PDF биш**, засварлаж бөглөх загвар. Багийн бодит гишүүн, хуваарилалтын код, GitHub холбоос, Mac дээрх тестийн үр дүн, screenshot-аа нэмээд эцсийн баримт болгож гаргана.
